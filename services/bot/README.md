# Telegram-бот

Принимает голосовое или аудиофайл, расшифровывает его через faster-whisper и определяет
тему классификатором из `src/newsbot/`. Отвечает расшифровкой и темой с уверенностью.

```
голосовое → проверка длины/размера → «⏳ Распознаю…» → скачивание
          → WhisperASR → классификатор → ответ (то же сообщение редактируется)
```

## Устройство

| Файл | Что делает |
|---|---|
| `config.py` | настройки из `.env` (токен, модели, лимиты) |
| `pipeline.py` | ASR + классификатор; модели работают в отдельном потоке, число одновременных задач ограничено |
| `messages.py` | тексты, проверка входа, форматирование ответа (без aiogram — легко тестировать) |
| `handlers.py` | обработчики Telegram |
| `__main__.py` | точка входа: грузит модели, затем запускает polling |

Модели загружаются **до** подключения к Telegram: если нет файла классификатора или
не скачался whisper, бот сразу падает с понятной ошибкой.

## Локальный запуск

```bash
cp .env.example .env              # вписать BOT_TOKEN от @BotFather
uv sync --group bot
uv run dvc pull                   # или положить text_baseline.joblib в ml/models/ вручную
uv run python -m services.bot
```

Без модели классификатора можно проверить бота на заглушке: `CLASSIFIER_BACKEND=stub` в `.env`.

## Docker

```bash
docker compose up -d --build      # из корня репозитория
docker compose logs -f bot
```

- `ml/models/` монтируется в контейнер только для чтения, в образ модель не попадает.
- Веса whisper скачиваются при первом старте в volume `whisper-cache` и переживают пересборку.
- В образе только основные зависимости и группа `bot`, без jupyter и инструментов разработки.

## Настройки

Все переменные с комментариями — в [`.env.example`](../../.env.example). Основные:

| Переменная | По умолчанию | |
|---|---|---|
| `BOT_TOKEN` | — | обязательна |
| `WHISPER_MODEL` | `small` | `tiny` быстрее, `medium` точнее |
| `CLASSIFIER_BACKEND` | `tfidf` | `stub` — заглушка без модели |
| `CLASSIFIER_MODEL_PATH` | `ml/models/text_baseline.joblib` | |
| `MIN_CONFIDENCE` | `0.0` | ниже порога ответ «тему определить не удалось» |
| `MAX_DURATION_SEC` | `300` | |
| `MAX_CONCURRENT_JOBS` | `1` | на CPU больше 1 обычно только замедляет |

## Тесты

`tests/test_bot.py` проверяет логику без Telegram и без настоящих моделей: лимиты,
форматирование, пропуск классификатора при пустой речи, ограничение параллельности,
обработку ошибок модели. Запуск: `uv run pytest tests/test_bot.py`.
