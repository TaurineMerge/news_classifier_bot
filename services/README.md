# Services

Здесь находятся запускаемые сервисы, которые используют общий пакет `newsbot`.

- [`bot/`](bot/README.md) — Telegram-бот: принимает голосовое, вызывает ASR и классификатор, отвечает темой.

Каждый сервис — отдельная папка со своим кодом и Dockerfile. Зависимости сервиса —
отдельная группа в корневом `pyproject.toml` (например, `bot`).
