# Итоговое исследование по ОЕЯ

[Исходный ноутбук](../../notebooks/02_nlp_final.ipynb) · [Выполненная версия HTML](02_nlp_final.html) · [Метрики](nlp_results.json)

Реализованы подготовка данных, три классические модели, TextCNN на PyTorch и fine-tuning RuBERT-tiny2. Считаются accuracy, macro-F1, weighted-F1, macro average precision one-vs-rest, матрицы ошибок, PR-кривые, срезы длины/OOV и примеры промахов.

## Запуск

Из корня репозитория установите окружение через uv sync --locked --group ml. Получите данные Lenta v3 из общего Google Drive и распакуйте в ml/data/. Откройте ml/notebooks/02_nlp_final.ipynb. RETRAIN=True выполняет обучение заново. В Colab выбирайте GPU и укажите путь к клонированному репозиторию в REPO_ROOT.

Для окружения с теми же версиями основных библиотек есть ml/requirements-nlp.txt. Полные версии выполненного запуска находятся в nlp_results.json. Чекпоинты создаются в ml/models/nlp_final и исключены из Git.

## Проверенные результаты

| Модель | Test accuracy | Test macro-F1 |
|---|---:|---:|
| LogisticRegression | 98,36% | 0,9837 |
| MultinomialNB | 97,54% | 0,9756 |
| LinearSVC | 98,91% | 0,9891 |
| TextCNN | 95,36% | 0,9535 |
| RuBERT-tiny2 | 99,73% | 0,9973 |

На валидации SVM и RuBERT имеют одинаковый macro-F1 0,9727. При равенстве ноутбук выбирает первую модель в порядке сравнения, поэтому выбран SVM. Test не использовался для разрешения равенства.

Все кодовые ячейки выполнены с повторным обучением. Метрики независимо пересчитаны по сохранённым оценкам. CNN и RuBERT после загрузки на CPU воспроизвели все 366 тестовых предсказаний. Графики просмотрены.

Это согласие с предварительными автоматическими метками Lenta. Test уже использовался в предыдущих исследованиях, поэтому не является новым закрытым тестом. Части ASR и сетевой интеграции бота проверяются отдельно.
